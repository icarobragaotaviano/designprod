# Modelos de textos e preços

PSDs originais usados por [Editar textos e preços](../../scripts/editar-textos-precos-rapido.jsx). Abra qualquer um deles antes de executar o editor. Consulte o [guia de uso](../../../../docs/textos-e-precos.md).

| Arquivo no repositório | Nome recebido | Tela |
|---|---|---|
| `texto-um-digito.psd` | `02-TEXTO-UM-DIGITO.psd` | 597 × 484 px |
| `texto-dois-digitos.psd` | `01-TEXTO-DOIS-DIGITOS.psd` | 706 × 468 px |

Os arquivos mantêm exatamente os bytes dos originais, incluindo camadas, guias e transparência. A fonte SF Pro Condensed Semibold precisa estar ativa para editar os textos; nenhum arquivo de fonte está incluído.

Os hashes SHA-256 e a estrutura de referência estão em [textos-precos-modelos.json](../../../../tools/fixtures/textos-precos-modelos.json). `npm run test:textos` compara os PSDs com os modelos incorporados no gerador histórico.

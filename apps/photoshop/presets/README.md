# Presets do Photoshop

Espaço para paletas (`.aco`), estilos (`.asl`), gradientes (`.grd`), pincéis (`.abr`) e formas (`.csh`) da marca.

Valem as mesmas regras dos actions: arquivo binário, um preset por arquivo, mudança descrita no commit.

Ainda não são lidos pelo catálogo — entram quando houver conteúdo suficiente para justificar.

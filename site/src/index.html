Como instalar

O jeito recomendado

Clone o repositório e deixe o instalador gravar os lançadores nos menus dos apps. Editar um script aqui já vale na próxima execução dentro do Adobe. 

git clone {{CLONE}}
cd designprod
npm run install:dev

Um script avulso

As ferramentas marcadas com precisa do core/ usam a biblioteca comum por #include e não rodam sozinhas — baixe o repositório inteiro. As demais são independentes: salve o .jsx e abra por Arquivo > Scripts > Procurar.

Painel dentro do Photoshop

O plugin UXP mostra esta mesma lista dentro do app, sem sair para o menu de scripts. O pacote é montado a cada publicação, então vem sempre com as ferramentas acima.

Antes de usar em produção: os scripts foram escritos contra as APIs documentadas de cada app e passam nos testes locais, mas ainda não foram executados dentro dos aplicativos Adobe. Rode cada um uma vez antes de confiar neles em um job.

Instalação

O jeito recomendado

Clone o repositório e deixe o instalador gravar os lançadores nos menus dos apps. Editar um script aqui já vale na próxima execução dentro do Adobe. 

git clone {{CLONE}}
cd designprod
npm run install:dev

Uma ferramenta só

O botão Baixar de cada cartão entrega um .jsx pronto, com a biblioteca do estúdio já embutida — nada de instalar o repositório. Para usar uma vez, abra por Arquivo > Scripts > Procurar.

Para deixar no menu, cole o arquivo na pasta de scripts do Photoshop e reinicie o app. Ele aparece em Arquivo > Scripts com o mesmo nome que o instalador usaria. 

macOS
/Applications/Adobe Photoshop [versão]/Presets/Scripts/

Windows
C:\Program Files\Adobe\Adobe Photoshop [versão]\Presets\Scripts\

Painel dentro do Photoshop

O plugin UXP mostra esta mesma lista dentro do app, sem sair para o menu de scripts. O pacote é montado a cada publicação, então vem sempre com as ferramentas acima.

Como instalar no Photoshop

Pelo Creative Cloud — arquivo .ccx

  1. Guarde o .ccx no mesmo drive onde o Photoshop está instalado: o instalador procura só no drive em que o arquivo estiver.
  2. Dê um duplo clique. Se não acontecer nada, clique com o botão direito e use Abrir com > Unified Plugin Installer Agent.
  3. O painel passa a aparecer no menu Plugins do Photoshop.

Pela linha de comando — arquivo .ccx

Instala sem abrir o Creative Cloud nem o UDT. Precisa do aplicativo Creative Cloud 5.7 ou mais novo instalado. 

macOS
"/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install /caminho/do/arquivo.ccx

Windows
"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install C:\caminho\do\arquivo.ccx

Pelo UXP Developer Tool — arquivo .zip

É o caminho para usar quando o Creative Cloud recusa o pacote por ele não ser assinado.

  1. No Photoshop, abra Preferências > Plugins e marque Ativar modo de desenvolvedor. No Windows o caminho é Editar > Preferências > Plugins. Reinicie o Photoshop.
  2. Instale o Adobe UXP Developer Tool pelo aplicativo Creative Cloud no seu computador.
  3. Descompacte o .zip numa pasta definitiva — o UDT aponta para ela, e apagar a pasta tira o painel do Photoshop.
  4. No UDT, clique em Add Plugin e escolha o manifest.json que está na raiz da pasta descompactada.
  5. Na linha do plugin, abra Actions e escolha Load.
  6. O painel abre no Photoshop. Se você fechar, reabra pelo menu Plugins.

Se o painel não estiver lá depois de reiniciar o Photoshop, carregue de novo pelo UDT.

O que não funciona

Copiar a pasta do plugin para dentro dos arquivos do Photoshop não instala o painel. Isso valia para os painéis CEP antigos; um plugin UXP também precisa de um registro que só o instalador da Adobe grava. Use um dos três caminhos acima. Para as ferramentas em .jsx, ao contrário, colar o arquivo na pasta é justamente o caminho certo — veja Uma ferramenta só.

Antes de usar em produção: os scripts foram escritos contra as APIs documentadas de cada app e passam nos testes locais, mas ainda não foram executados dentro dos aplicativos Adobe. Rode cada um uma vez antes de confiar neles em um job.
